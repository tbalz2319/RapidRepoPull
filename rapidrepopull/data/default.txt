# RapidRepoPull -- default repository list
#
# One repository per line. '#' starts a comment, blank lines are ignored.
# Any of these forms work:
#
#   owner/repo
#   https://github.com/owner/repo
#   https://github.com/owner/repo.git
#   git@github.com:owner/repo.git
#
# '# @tag: name' labels every repository after it, until the next such
# directive. Clone one group on its own with, for example:
#
#   rapidrepopull --tag wordlists,recon
#
# 'rapidrepopull --list-tags' prints the groups this file defines.
#
# Curation rule: an entry earns its place by being maintained OR by being
# finished and still standard. Abandoned tools and ones with a living
# successor are moved to the bottom of this file with a reason, not deleted,
# so nobody re-adds them a year from now.
#
# Checked on 2026-09-20 with 'rapidrepopull --doctor', and the dates below are
# each project's last commit on its default branch. Note that GitHub's
# pushed_at is NOT that date -- it moves on a push to any branch, which made
# several of these look years fresher than they are.
